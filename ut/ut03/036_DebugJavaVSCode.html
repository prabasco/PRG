    Depuración de programas Java con Visual Studio Code¶

    1. ¿Qué es depurar un programa?¶

    Depurar (debugging) consiste en localizar, analizar y corregir errores de un programa. Un depurador (debugger) permite detener temporalmente su ejecución, observar los valores de las variables y ejecutar instrucciones una a una.

    Es importante distinguir:

    • Errores de compilación: impiden compilar el programa, por ejemplo, una llave sin cerrar.
    • Errores de ejecución: aparecen mientras se ejecuta, por ejemplo, una división entre cero.
    • Errores lógicos: el programa se ejecuta, pero produce resultados incorrectos.

    Con el depurador podemos investigar especialmente los errores de ejecución y los errores lógicos, sin llenar el código de instrucciones System.out.println().

    2. Preparación del entorno¶

    Para depurar Java con Visual Studio Code necesitamos:

    1. Tener instalado un JDK y comprobarlo en una terminal:
    java -version
javac -version
    1. Instalar Visual Studio Code.
    2. Instalar desde Extensiones (Ctrl+Shift+X) el paquete Extension Pack for Java, que incluye Debugger for Java.
    3. Abrir en VS Code la carpeta que contiene nuestro código mediante Archivo > Abrir carpeta.

    Proyecto de ejemplo

    Para los primeros ejercicios basta con crear una carpeta y guardar dentro un fichero Main.java. No es necesario utilizar Maven ni Gradle.

    3. Primer programa para depurar¶

    Guarda este ejemplo en Main.java:

    public class Main {
    public static void main(String[] args) {
        int numero1 = 10;
        int numero2 = 5;
        int suma = numero1 + numero2;
        int doble = suma * 2;

        System.out.println("Suma: " + suma);
        System.out.println("Doble: " + doble);
    }
}

    3.1. Crear un punto de interrupción (breakpoint)¶

    Un punto de interrupción indica al depurador dónde debe detener el programa antes de ejecutar la instrucción correspondiente.

    1. Abre Main.java.
    2. Haz clic en el margen izquierdo, junto al número de línea de int suma = numero1 + numero2;.
    3. Aparecerá un círculo rojo que identifica el punto de interrupción.
    4. Pulsa F5 o selecciona Ejecutar > Iniciar depuración.
    5. El programa se detendrá en esa línea. Las variables numero1 y numero2 ya tendrán valor, pero la asignación a suma todavía no se habrá ejecutado.

    Para quitar el punto de interrupción, vuelve a pulsar sobre el círculo rojo.

    3.2. Controles de ejecución¶

    Acción Tecla Función
    Continuar (Continue) F5 Reanuda el programa hasta el siguiente punto de interrupción o hasta que termine.
    Pasar por encima (Step Over) F10 Ejecuta la instrucción actual sin entrar en los métodos llamados.
    Entrar (Step Into) F11 Entra en un método llamado desde la instrucción actual, cuando es posible.
    Salir (Step Out) Shift+F11 Ejecuta hasta salir del método actual y volver al método que lo llamó.
    Reiniciar (Restart) Ctrl+Shift+F5 Inicia de nuevo la sesión de depuración.
    Detener (Stop) Shift+F5 Finaliza la sesión de depuración.

    Diferencia entre F5 y F10

    F5 continúa la ejecución sin detenerse en cada línea; F10 avanza una instrucción o línea depurable cada vez. Son las dos operaciones más utilizadas al empezar.

    4. Panel Ejecutar y depurar (Run and Debug)¶

    Abre el panel mediante Ctrl+Shift+D. Durante una sesión de depuración encontrarás estas secciones:

    Sección Utilidad
    Variables Muestra los valores de las variables accesibles en el contexto actual.
    Watch / Inspección Permite seguir variables o evaluar expresiones elegidas por el programador.
    Call Stack / Pila de llamadas Indica qué métodos se han llamado y cuál está ejecutándose.
    Breakpoints / Puntos de interrupción Permite consultar, activar o desactivar los puntos de interrupción.

    4.1. Observar variables¶

    Con el ejemplo anterior detenido en la línea de suma, observa los valores de numero1 y numero2. Pulsa F10 y comprueba que aparece suma = 15. Vuelve a pulsar F10 para ejecutar la asignación a doble y observar doble = 30.

    4.2. Inspeccionar expresiones con Watch¶

    En Watch, pulsa el símbolo + y escribe expresiones como:

    numero1 + numero2
suma * 2
numero1 > numero2

    El depurador evaluará las expresiones cuando las variables estén disponibles en el contexto actual.

    4.3. Consola de depuración¶

    La Debug Console permite consultar expresiones durante una pausa. No debe confundirse con el terminal integrado: la consola de depuración no admite la entrada interactiva de Scanner. Para programas que leen del teclado, utiliza el terminal integrado.

    5. Ejemplo: localizar un error lógico¶

    El siguiente programa pretende calcular la media de tres notas, pero contiene un error:

    public class Main {
    public static void main(String[] args) {
        double nota1 = 6;
        double nota2 = 8;
        double nota3 = 10;

        double suma = nota1 + nota2 + nota3;
        double media = suma / 2; // ERROR: son tres notas

        System.out.println("Media: " + media);
    }
}

    Proceso de depuración:

    1. Coloca un breakpoint en double suma = ....
    2. Ejecuta con F5.
    3. Avanza con F10 y comprueba que suma vale 24.
    4. Avanza otra vez y observa que media vale 12.0, un valor incorrecto para estas notas.
    5. Identifica el problema: se divide entre 2 en lugar de entre 3.
    6. Detén la ejecución, cambia la línea por double media = suma / 3; y vuelve a depurar.

    Resultado correcto: Media: 8.0.

    6. Ejemplo: entrar en un método con F11¶

    public class Main {
    public static int cuadrado(int numero) {
        int resultado = numero * numero;
        return resultado;
    }

    public static void main(String[] args) {
        int valor = 4;
        int calculo = cuadrado(valor);
        System.out.println(calculo);
    }
}
    1. Coloca un breakpoint en int calculo = cuadrado(valor);.
    2. Inicia la depuración con F5.
    3. Pulsa F11: el depurador entra en el método cuadrado().
    4. Comprueba que el parámetro numero vale 4.
    5. Pulsa F10 para calcular resultado = 16.
    6. Pulsa Shift+F11 para regresar a main().
    7. Examina Call Stack mientras estés dentro del método para observar las llamadas.

    F10 frente a F11

    Si hubieras pulsado F10 en la llamada a cuadrado(valor), el método se habría ejecutado sin mostrarte sus instrucciones internas.

    7. Depurar bucles y condiciones¶

    public class Main {
    public static void main(String[] args) {
        int suma = 0;

        for (int i = 1; i <= 5; i++) {
            suma += i;
        }

        System.out.println("Resultado: " + suma);
    }
}

    Coloca un breakpoint en suma += i; y ejecuta el programa. Cada vez que pulses F5, el depurador se detendrá en la siguiente iteración. Observa cómo cambian i y suma:

    Iteración i suma antes suma después
    1 1 0 1
    2 2 1 3
    3 3 3 6
    4 4 6 10
    5 5 10 15

    7.1. Breakpoints condicionales¶

    Si solo interesa detenerse cuando i == 4:

    1. Haz clic derecho sobre el punto de interrupción.
    2. Selecciona Edit Breakpoint / Editar punto de interrupción.
    3. Establece una expresión condicional:
    i == 4
    1. Continúa la ejecución: el programa solo se detendrá en ese punto cuando la condición sea verdadera.

    7.2. Logpoints¶

    Un logpoint muestra información en la consola de depuración sin detener el programa. Se configura desde el margen izquierdo del editor, con Add Logpoint / Agregar punto de registro. Es útil para observar el comportamiento de un bucle sin modificar el código fuente.

    8. Depurar programas con Scanner¶

    import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Introduce un número: ");
        int numero = sc.nextInt();

        int doble = numero * 2;
        System.out.println("Doble: " + doble);

        sc.close();
    }
}

    Coloca un breakpoint en int doble = numero * 2; e inicia la depuración. Introduce un número en el terminal integrado y pulsa Intro. El programa se detendrá después de leerlo y podrás examinar numero.

    Si la entrada de teclado no funciona, configura la consola como terminal integrado (véase el apartado siguiente).

    9. Configuración opcional: launch.json¶

    En ejercicios sencillos normalmente no necesitas crear launch.json: VS Code puede detectar y depurar automáticamente la clase con main().

    Si quieres personalizar la ejecución, crea el fichero .vscode/launch.json en la carpeta del proyecto:

    {
  "version": "0.2.0",
  "configurations": [
    {
      "type": "java",
      "name": "Depurar Main",
      "request": "launch",
      "mainClass": "Main",
      "console": "integratedTerminal",
      "stopOnEntry": false
    }
  ]
}
    • type: indica que se utiliza el depurador de Java.
    • request: launch inicia una nueva ejecución.
    • mainClass: clase que contiene main(); si pertenece a un paquete, utiliza el nombre completo, por ejemplo com.ejemplo.Main.
    • console: utiliza el terminal integrado para permitir Scanner.
    • stopOnEntry: indica si se detiene al entrar al programa.

    10. Problemas frecuentes¶

    Problema Posible solución
    No aparece Run / Debug Instala Extension Pack for Java y espera a que finalice la carga de Java.
    F5 no inicia la depuración Comprueba que has abierto una carpeta y que existe un método main() válido.
    No se detiene en un breakpoint Comprueba que está activado y que la línea se ejecuta realmente.
    Scanner no permite introducir datos Usa "console": "integratedTerminal".
    Los valores de las variables no aparecen Detén el programa en un punto donde estén dentro de su ámbito (scope).
    El código no compila Corrige primero los errores de sintaxis o compilación.

    11. Actividades prácticas¶

    Actividad 1. Seguimiento de variables¶

    Depura el programa del apartado 3 y anota el valor de cada variable después de cada instrucción. Identifica qué variables todavía no han sido inicializadas en cada pausa.

    Actividad 2. Detectar un error lógico¶

    Depura el programa de la media del apartado 5. Explica qué operación es incorrecta, cómo lo has detectado y cuál es el resultado correcto.

    Actividad 3. Depuración de bucles¶

    En el programa del apartado 7, utiliza un breakpoint condicional para detener la ejecución únicamente cuando i == 4. Anota los valores de i y suma antes y después de ejecutar el cuerpo del bucle.

    Actividad 4. Depuración de métodos¶

    En el programa del apartado 6, compara el comportamiento de F10 y F11 sobre la llamada a cuadrado(). Examina la pila de llamadas y el valor del parámetro.
