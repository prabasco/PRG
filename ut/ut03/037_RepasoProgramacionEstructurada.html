    Repaso - Programación estructurada¶

    Objetivos

    Comprender las tres estructuras fundamentales de control, seleccionar la adecuada para cada problema y escribir programas Java claros, verificables y sin bucles infinitos.

    1. Introducción a la programación estructurada¶

    La programación estructurada organiza las instrucciones en bloques con un flujo de ejecución claro. Facilita la lectura, el mantenimiento, las pruebas y la depuración del código.

    Se apoya en tres ideas:

    • Diseño descendente: dividir un problema complejo en tareas pequeñas.
    • Estructuras de control limitadas: secuencia, selección e iteración.
    • Ámbitos delimitados: limitar dónde existen y se utilizan las variables.

    1.1. Teorema de Böhm-Jacopini¶

    El teorema de Böhm-Jacopini (1966) establece que cualquier algoritmo computable representable mediante un diagrama de flujo puede expresarse utilizando las estructuras de secuencia, selección e iteración. Por ello, no es necesario recurrir a saltos arbitrarios como goto para escribir algoritmos.

    flowchart TD
    A[Programación estructurada] --> B[Secuencia]
    A --> C[Selección]
    A --> D[Iteración]
    B --> E[Instrucciones en orden]
    C --> F[Elegir según una condición]
    D --> G[Repetir instrucciones]

    1.2. Bloques y ámbito de variables¶

    En Java, las llaves { } delimitan bloques de código. Una variable local declarada dentro de un bloque solo es accesible dentro de su ámbito.

    public class Main {
    public static void main(String[] args) {
        int edad = 19;
        if (edad >= 18) {
            String mensaje = "Mayor de edad";
            System.out.println(mensaje);
        }
        // System.out.println(mensaje); // Error: fuera de ámbito
    }
}

    2. Estructura secuencial¶

    Las instrucciones se ejecutan una tras otra, en el orden en que aparecen, salvo que alguna cambie el flujo.

    flowchart TD
    A([Inicio]) --> B[/Leer a y b/]
    B --> C[Calcular suma = a + b]
    C --> D[/Mostrar suma/]
    D --> E([Fin])

    Ejemplo: sumar dos números.

    import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Primer número: ");
        int a = sc.nextInt();
        System.out.print("Segundo número: ");
        int b = sc.nextInt();
        int suma = a + b;
        System.out.println("Suma: " + suma);
        sc.close();
    }
}

    Ejecución: para a = 7 y b = 5, el programa muestra Suma: 12.

    3. Estructuras de selección¶

    Permiten elegir qué instrucciones ejecutar a partir de una condición. En Java, una condición utilizada en if debe producir un valor boolean.

    3.1. Alternativa simple: if¶

    Ejecuta el bloque únicamente cuando la condición es verdadera.

    if (condicion) {
    // Instrucciones cuando la condición es verdadera
}

    flowchart TD
    A([Inicio]) --> B{¿a es distinto de 0?}
    B -->|Sí| C[Calcular x = b / a]
    C --> D[/Mostrar x/]
    B -->|No| E([Continuar])
    D --> E

    Ejemplo: división solo cuando el divisor es distinto de cero.

    int a = 4;
int b = 20;
if (a != 0) {
    double x = (double) b / a;
    System.out.println("Resultado: " + x);
}

    3.2. Alternativa doble: if-else¶

    Ejecuta uno de dos bloques excluyentes.

    if (condicion) {
    // Rama verdadera
} else {
    // Rama falsa
}

    flowchart TD
    A([Inicio]) --> B{¿Divisor distinto de cero?}
    B -->|Sí| C[Calcular división]
    B -->|No| D[/Mostrar error/]
    C --> E[/Mostrar resultado/]
    D --> F([Fin])
    E --> F
    int divisor = 0;
int dividendo = 20;
if (divisor != 0) {
    System.out.println((double) dividendo / divisor);
} else {
    System.out.println("Error: división por cero");
}

    3.3. Condicionales anidados y else if¶

    Un condicional puede contener otros. En Java, un else se asocia al if más cercano que todavía no tenga else. Las llaves evitan ambigüedades.

    Ejemplo: obtener el mayor de tres números.

    int a = 12, b = 18, c = 9;
int mayor;
if (a >= b && a >= c) {
    mayor = a;
} else if (b >= a && b >= c) {
    mayor = b;
} else {
    mayor = c;
}
System.out.println("Mayor: " + mayor);

    flowchart TD
    A([Inicio]) --> B{¿a >= b y a >= c?}
    B -->|Sí| C[mayor = a]
    B -->|No| D{¿b >= a y b >= c?}
    D -->|Sí| E[mayor = b]
    D -->|No| F[mayor = c]
    C --> G[/Mostrar mayor/]
    E --> G
    F --> G

    3.4. Alternativa múltiple: switch¶

    Selecciona una rama en función del valor de una expresión. La forma clásica emplea case, break y, opcionalmente, default.

    int dia = 3;
switch (dia) {
    case 1:
        System.out.println("Lunes");
        break;
    case 2:
        System.out.println("Martes");
        break;
    case 3:
        System.out.println("Miércoles");
        break;
    case 4:
        System.out.println("Jueves");
        break;
    case 5:
        System.out.println("Viernes");
        break;
    case 6:
    case 7:
        System.out.println("Fin de semana");
        break;
    default:
        System.out.println("Día inválido");
}

    flowchart TD
    A([Inicio]) --> B{Valor de opción}
    B -->|1| C[Acción 1]
    B -->|2| D[Acción 2]
    B -->|3| E[Acción 3]
    B -->|Otro| F[Opción inválida]
    C --> G([Fin])
    D --> G
    E --> G
    F --> G

    Uso de break

    En el switch clásico, si se omite break, la ejecución continúa por los siguientes case (fall-through), hasta encontrar un break o terminar el switch. Agrupar varios case sin instrucciones intermedias permite compartir una misma acción.

    Forma moderna de switch con flechas:

    int opcion = 2;
switch (opcion) {
    case 1 -> System.out.println("Añadir");
    case 2 -> System.out.println("Consultar");
    case 3 -> System.out.println("Salir");
    default -> System.out.println("Opción incorrecta");
}

    Las ramas con -> no necesitan break para evitar el paso a la siguiente rama.

    3.5. Operador condicional ?:¶

    Permite elegir entre dos expresiones y devolver un valor.

    int edad = 17;
String resultado = (edad >= 18) ? "Mayor de edad" : "Menor de edad";
System.out.println(resultado);

    Su uso resulta adecuado para expresiones breves; para decisiones complejas suele ser más legible if-else.

    4. Estructuras iterativas o bucles¶

    Un bucle repite instrucciones mientras se cumpla una condición. Es necesario definir correctamente la condición y modificar el estado que determina cuándo termina.

    4.1. Bucle while (mientras)¶

    Evalúa la condición antes de cada iteración. El cuerpo puede ejecutarse cero veces.

    while (condicion) {
    // Instrucciones repetidas
}

    flowchart TD
    A([Inicio]) --> B[contador = 1]
    B --> C{¿contador <= n?}
    C -->|Sí| D[/Mostrar contador/]
    D --> E[contador++]
    E --> C
    C -->|No| F([Fin])

    Ejemplo: números del 1 al N.

    int n = 5;
int contador = 1;
while (contador <= n) {
    System.out.println(contador);
    contador++;
}

    Salida: 1, 2, 3, 4, 5, en líneas independientes.

    Bucle infinito

    Si contador no se incrementa, la condición contador <= n puede permanecer siempre verdadera. La terminación debe verificarse para las entradas previstas.

    4.2. Bucle do-while (hacer mientras)¶

    Evalúa la condición después de ejecutar el cuerpo; por tanto, se ejecuta al menos una vez.

    do {
    // Instrucciones repetidas
} while (condicion);

    flowchart TD
    A([Inicio]) --> B[/Mostrar menú y leer opción/]
    B --> C{¿Opción distinta de 3?}
    C -->|Sí| B
    C -->|No| D([Fin])

    Ejemplo: menú que se repite hasta elegir salir.

    import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int opcion;
        do {
            System.out.println("1. Hola");
            System.out.println("2. Adiós");
            System.out.println("3. Salir");
            System.out.print("Opción: ");
            opcion = sc.nextInt();
            if (opcion == 1) {
                System.out.println("Hola");
            } else if (opcion == 2) {
                System.out.println("Adiós");
            } else if (opcion != 3) {
                System.out.println("Opción no válida");
            }
        } while (opcion != 3);
        sc.close();
    }
}

    4.3. Bucle for (para)¶

    Reúne inicialización, condición y actualización en una misma cabecera. Es especialmente útil cuando se conoce el número de iteraciones.

    for (inicializacion; condicion; actualizacion) {
    // Instrucciones repetidas
}

    flowchart TD
    A([Inicio]) --> B[i = 1]
    B --> C{¿i <= 5?}
    C -->|Sí| D[/Mostrar i/]
    D --> E[i++]
    E --> C
    C -->|No| F([Fin])
    for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}

    Variable de control

    En for (int i = 1; ...), i solo está disponible dentro del bucle. En Java es técnicamente posible modificarla en el cuerpo, pero generalmente debe evitarse para mantener la lógica clara.

    4.4. Contadores, acumuladores y productorios¶

    Un contador registra cuántas veces ocurre algo; un acumulador guarda un resultado parcial.

    Sumatorio de 1 a N:

    int n = 5;
int suma = 0;
for (int i = 1; i <= n; i++) {
    suma += i;
}
System.out.println("Suma: " + suma); // 15

    Factorial de N:

    int n = 5;
long factorial = 1;
for (int i = 2; i <= n; i++) {
    factorial *= i;
}
System.out.println("Factorial: " + factorial); // 120

    Restricciones

    El factorial está definido para enteros no negativos. Un long solo permite representar factoriales exactos hasta 20!; para valores superiores puede utilizarse BigInteger.

    4.5. Comparación de bucles¶

    Estructura Cuándo comprueba la condición Mínimo de ejecuciones Uso habitual
    while Antes del cuerpo 0 Repetición de duración indeterminada
    do-while Después del cuerpo 1 Menús y validación de entradas
    for Antes del cuerpo 0 Recorridos y repeticiones con contador

    5. Formas de controlar los bucles¶

    5.1. Bucles controlados por contador¶

    Se ejecutan según el valor de una variable numérica.

    int intentos = 0;
while (intentos < 3) {
    System.out.println("Intento " + (intentos + 1));
    intentos++;
}

    5.2. Bucles controlados por indicador (flag)¶

    Una variable boolean determina si debe continuar la repetición.

    Ejemplo: comprobar que todas las cifras de un entero no negativo son menores que 5.

    int numero = 2341;
int auxiliar = numero;
boolean todasMenores = true;
while (auxiliar > 0 && todasMenores) {
    int cifra = auxiliar % 10;
    if (cifra >= 5) {
        todasMenores = false;
    }
    auxiliar /= 10;
}
System.out.println(todasMenores
        ? "Todas las cifras son menores que 5"
        : "Hay alguna cifra mayor o igual que 5");

    Para 0 también se obtiene correctamente true. Para números negativos debe establecerse una regla de tratamiento del signo.

    5.3. Bucles controlados por centinela¶

    Un centinela es un valor especial que indica el final de la entrada y que no debe incluirse en el procesamiento.

    Ejemplo: sumar enteros hasta introducir 0.

    import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int suma = 0;
        System.out.print("Número (0 para terminar): ");
        int numero = sc.nextInt();
        while (numero != 0) {
            suma += numero;
            System.out.print("Número (0 para terminar): ");
            numero = sc.nextInt();
        }
        System.out.println("Suma total: " + suma);
        sc.close();
    }
}

    flowchart TD
    A([Inicio]) --> B[suma = 0]
    B --> C[/Leer número/]
    C --> D{¿Número distinto de 0?}
    D -->|Sí| E[suma = suma + número]
    E --> C
    D -->|No| F[/Mostrar suma/]
    F --> G([Fin])

    5.4. Ejemplo ampliado: detectar números capicúa¶

    Un número es capicúa cuando sus cifras se leen igual de izquierda a derecha y viceversa (por ejemplo, 1221). Esta versión invierte matemáticamente las cifras y compara el resultado.

    int numero = 1221;
int auxiliar = numero;
long invertido = 0;
while (auxiliar > 0) {
    invertido = invertido * 10 + auxiliar % 10;
    auxiliar /= 10;
}
boolean capicua = numero >= 0 && numero == invertido;
System.out.println(capicua ? "Es capicúa" : "No es capicúa");

    6. Bucles anidados¶

    Un bucle anidado se encuentra dentro de otro. Por cada iteración del bucle exterior, el interior realiza todas sus iteraciones previstas.

    Ejemplo: tablas de multiplicar del 1 al 10.

    for (int i = 1; i <= 10; i++) {
    System.out.println("Tabla del " + i);
    for (int j = 1; j <= 10; j++) {
        System.out.println(i + " x " + j + " = " + (i * j));
    }
    System.out.println();
}

    flowchart TD
    A([Inicio]) --> B[i = 1]
    B --> C{¿i <= 10?}
    C -->|Sí| D[j = 1]
    D --> E{¿j <= 10?}
    E -->|Sí| F[/Mostrar i x j/]
    F --> G[j++]
    G --> E
    E -->|No| H[i++]
    H --> C
    C -->|No| I([Fin])

    El ejemplo realiza 10 × 10 = 100 operaciones de multiplicación. Los bucles anidados también se utilizan para recorrer matrices y generar patrones de filas y columnas.

    7. Sentencias de salto y control del flujo (ampliación)¶

    7.1. break¶

    Finaliza inmediatamente el bucle más interno que lo contiene.

    for (int i = 1; i <= 10; i++) {
    if (i == 5) {
        break;
    }
    System.out.println(i);
}
// Muestra 1, 2, 3 y 4

    7.2. continue¶

    Omite el resto del cuerpo de la iteración actual y continúa con la siguiente iteración.

    for (int i = 1; i <= 6; i++) {
    if (i % 2 != 0) {
        continue;
    }
    System.out.println(i);
}
// Muestra 2, 4 y 6

    7.3. Saltos con etiquetas¶

    Java permite etiquetar un bucle para utilizar break etiqueta; o continue etiqueta;. Son válidos, aunque conviene reservarlos para casos donde mejoren la claridad.

    exterior:
for (int fila = 1; fila <= 3; fila++) {
    for (int columna = 1; columna <= 3; columna++) {
        if (fila == 2 && columna == 2) {
            break exterior;
        }
        System.out.println(fila + ", " + columna);
    }
}

    8. Buenas prácticas¶

    • Utilizar llaves incluso cuando el bloque contenga una sola instrucción.
    • Elegir nombres descriptivos para las variables.
    • Mantener una indentación uniforme.
    • Comprobar las condiciones límite: cero iteraciones, una iteración y valores extremos.
    • Evitar bucles infinitos y modificaciones inesperadas del contador.
    • Inicializar correctamente contadores (0), sumas (0) y productos (1).
    • Comentar el motivo de una decisión cuando no resulte evidente, sin repetir literalmente el código.
    • Separar la lectura de datos, los cálculos y la presentación de resultados cuando el programa crezca.

    9. Resumen¶

    flowchart TD
    A{¿Qué necesita el algoritmo?}
    A -->|Ejecutar pasos en orden| B[Secuencia]
    A -->|Elegir entre alternativas| C{¿Cuántas alternativas?}
    C -->|Dos o condiciones complejas| D[if / else]
    C -->|Varios valores concretos| E[switch]
    A -->|Repetir instrucciones| F{¿Se ejecuta al menos una vez?}
    F -->|Sí| G[do-while]
    F -->|No| H{¿Contador de iteraciones?}
    H -->|Sí| I[for]
    H -->|No| J[while]
