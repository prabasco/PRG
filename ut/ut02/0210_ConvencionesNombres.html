    Convenciones de nombres en Java¶

    Cuando programamos debemos elegir nombres para las variables, métodos, clases, constantes, etc. Estos nombres reciben de forma general el nombre de identificadores.

    Por ejemplo:

    int edadAlumno = 18;
double notaMedia = 7.5;

    Java establece unas reglas obligatorias para crear identificadores, pero además existen convenciones de nomenclatura (naming conventions) que indican cómo deberíamos escribirlos para conseguir un código más legible y uniforme.

    Regla y convención no son lo mismo

    Una regla del lenguaje debe cumplirse obligatoriamente para que el código sea válido.

    Una convención es una recomendación sobre cómo escribir el código.

    Por ejemplo:

    int numeroalumnos = 25;
int NumeroAlumnos = 25;
int numeroAlumnos = 25;

    Las tres declaraciones pueden ser válidas para Java, pero para una variable la forma recomendada es:

    int numeroAlumnos = 25;

    camelCase¶

    camelCase es una convención de escritura en la que varias palabras se escriben juntas, sin espacios, utilizando letras mayúsculas para indicar dónde comienza cada nueva palabra.

    Su nombre procede de la similitud de las letras mayúsculas intermedias con las jorobas de un camello.

    Por ejemplo:

    numeroAlumnos
precioProducto
nombreCompleto
fechaNacimiento

    Existen principalmente dos variantes de Camel Case:

    • lowerCamelCase
    • UpperCamelCase, también denominado PascalCase

    Más información sobre Camel Case en Wikipedia

    lowerCamelCase¶

    En lowerCamelCase, la primera palabra comienza con minúscula y las siguientes palabras comienzan con mayúscula.

    nombre
nombreAlumno
nombreCompletoAlumno

    La estructura sería:

    primeraPalabraSegundaPalabraTerceraPalabra

    En Java se utiliza principalmente para:

    • Variables.
    • Atributos.
    • Parámetros.
    • Métodos.

    Variables¶

    int edadAlumno = 18;

double precioProducto = 29.95;

String nombreCompleto = "Ana García";

boolean mayorDeEdad = true;

    Evitar nombres como:

    int edadalumno;
int EdadAlumno;
int edad_alumno;

    La forma recomendada en Java sería:

    int edadAlumno;

    Métodos¶

    Los métodos también utilizan normalmente lowerCamelCase:

    calcularPrecio();
mostrarDatos();
obtenerNombre();
calcularNotaMedia();

    Además, los nombres de los métodos suelen comenzar con un verbo, ya que representan una acción.

    Por ejemplo:

    public void mostrarDatos() {
    // ...
}

    public double calcularPrecioFinal() {
    // ...
}

    public String obtenerNombreCompleto() {
    // ...
}

    Ejemplo

    int numeroAlumnos = 25;
double notaMedia = 7.8;
String nombreModulo = "Programación";

calcularNotaMedia();
mostrarResultados();

    PascalCase o UpperCamelCase¶

    En PascalCase todas las palabras, incluida la primera, comienzan con mayúscula.

    Alumno
Producto
CuentaBancaria
VehiculoElectrico

    Su estructura es:

    PrimeraPalabraSegundaPalabraTerceraPalabra

    En Java se utiliza principalmente para los nombres de:

    • Clases.
    • Interfaces.
    • Enumeraciones.
    • Otros tipos definidos por el programador.

    Por ejemplo:

    public class Alumno {

}

    Otro ejemplo:

    public class CuentaBancaria {

}

    Una clase formada por varias palabras podría llamarse:

    public class VehiculoElectrico {

}

    y no:

    public class vehiculoElectrico { }
public class vehiculo_electrico { }
public class VEHICULOELECTRICO { }

    Clases y objetos

    Podemos observar la diferencia entre el nombre de una clase y una variable que contiene un objeto:

    Alumno alumno = new Alumno();

    En este código:

    • Alumno → PascalCase, porque es una clase.
    • alumno → camelCase, porque es una variable.

    Otro ejemplo:

    CuentaBancaria cuentaBancaria = new CuentaBancaria();
    • CuentaBancaria → clase → PascalCase
    • cuentaBancaria → variable → camelCase

    snake_case¶

    En snake_case las diferentes palabras se escriben en minúsculas y se separan mediante el carácter _ (underscore o guion bajo).

    nombre_alumno
precio_producto
fecha_nacimiento
numero_alumnos

    Su estructura es:

    primera_palabra_segunda_palabra

    Por ejemplo:

    int numero_alumnos = 25;
String nombre_alumno = "Laura";

    Este código es válido en Java, pero no sigue la convención habitual de Java para variables.

    En Java deberíamos escribir:

    int numeroAlumnos = 25;
String nombreAlumno = "Laura";

    snake_case y Java

    Aunque Java permite utilizar _ dentro de los identificadores, normalmente no utilizaremos snake_case para variables o métodos.

    // Válido, pero no recomendado en Java
int numero_alumnos = 25;

// Convención habitual de Java
int numeroAlumnos = 25;

    Más información sobre snake_case en Wikipedia

    SCREAMING_SNAKE_CASE¶

    Existe una variante de snake_case denominada SCREAMING_SNAKE_CASE.

    Las palabras se escriben completamente en mayúsculas y se separan mediante _.

    EDAD_MINIMA
PRECIO_MAXIMO
NUMERO_MAXIMO_INTENTOS
IVA_GENERAL

    En Java esta convención se utiliza para nombrar constantes.

    Por ejemplo:

    final int EDAD_MINIMA = 18;
final double PI = 3.141592;

    Es especialmente habitual con constantes de clase declaradas mediante static final:

    public static final int MAXIMO_INTENTOS = 3;

public static final double IVA = 0.21;

public static final double VELOCIDAD_MAXIMA = 120.0;

    Por ejemplo:

    public class Configuracion {

    public static final int MAXIMO_INTENTOS = 3;
    public static final double IVA_GENERAL = 0.21;
}

    Podríamos utilizarlas mediante:

    System.out.println(Configuracion.MAXIMO_INTENTOS);
System.out.println(Configuracion.IVA_GENERAL);

    Comparación de las diferentes convenciones¶

    Partiendo del concepto:

    número máximo de alumnos

    podríamos representarlo utilizando diferentes convenciones:

    Convención Ejemplo
    camelCase numeroMaximoAlumnos
    PascalCase NumeroMaximoAlumnos
    snake_case numero_maximo_alumnos
    SCREAMING_SNAKE_CASE NUMERO_MAXIMO_ALUMNOS

    Cada una tiene diferentes usos.

    En Java utilizaremos principalmente:

    Elemento Convención Ejemplo
    Variable camelCase numeroAlumnos
    Atributo camelCase precioProducto
    Parámetro camelCase edadAlumno
    Método camelCase calcularNotaMedia()
    Clase PascalCase CuentaBancaria
    Interface PascalCase Serializable
    Enum PascalCase EstadoPedido
    Constante SCREAMING_SNAKE_CASE MAXIMO_INTENTOS
    Paquete minúsculas com.ejemplo.productos

    Ejemplo completo¶

    En el siguiente código aparecen varias de las convenciones anteriores:

    public class CuentaBancaria {

    public static final double COMISION_MAXIMA = 10.0;

    private String nombreTitular;
    private double saldoActual;

    public CuentaBancaria(String nombreTitular) {
        this.nombreTitular = nombreTitular;
        this.saldoActual = 0;
    }

    public void ingresarDinero(double cantidad) {
        saldoActual += cantidad;
    }

    public double obtenerSaldoActual() {
        return saldoActual;
    }
}

    Podemos identificar:

    Identificador Tipo Convención
    CuentaBancaria Clase PascalCase
    COMISION_MAXIMA Constante SCREAMING_SNAKE_CASE
    nombreTitular Variable camelCase
    saldoActual Variable camelCase
    ingresarDinero() Método camelCase
    obtenerSaldoActual() Método camelCase
    cantidad Parámetro camelCase

    Regla práctica para Java

    Para comenzar a programar en Java podemos recordar tres reglas principales:

    Variables y métodos → camelCase

Clases             → PascalCase

Constantes         → SCREAMING_SNAKE_CASE

    Ejemplo:

    public class ProductoElectronico {

    public static final double IVA_GENERAL = 0.21;

    String nombreProducto;
    double precioProducto;

    public void mostrarInformacion() {
        // ...
    }
}
