    UT 05. Operaciones con arrays en Java¶

    1. Qué operaciones podemos realizar¶

    Una vez creado un array, podemos consultar y modificar sus elementos, recorrerlo, buscar valores, copiarlo y ordenar su contenido.

    Su longitud es fija. Para insertar o eliminar posiciones hay que crear otro array o gestionar una zona ocupada dentro de un array con capacidad disponible.

    Operación Efecto
    Modificar una posición Sustituye un valor; conserva el tamaño.
    Insertar en un array nuevo Crea una posición adicional y desplaza los valores posteriores.
    Eliminar en un array nuevo Omite una posición y devuelve un array más pequeño.
    Borrado lógico Marca o deja de considerar un dato; conserva el tamaño físico.
    Ordenar Reorganiza los elementos.
    Buscar Localiza un valor sin modificar el contenido.

    Los ejemplos trabajan con arrays unidimensionales. Salvo que se indique lo contrario, los métodos reciben arrays no nulos. Los fragmentos con instrucciones se escriben dentro de main; los métodos static, dentro de una clase y fuera de main.

    Uso de métodos de biblioteca

    Los algoritmos manuales permiten comprender las operaciones. El apartado de java.util.Arrays muestra las herramientas de biblioteca. En las actividades se mantienen las restricciones del documento original.

    2. Acceso y modificación¶

    2.1. Consultar y actualizar una posición¶

    int[] unidades = {10, 20, 30};

System.out.println(unidades[1]); // 20
unidades[1] = 25;                // Sustitución
unidades[0]++;                   // Incremento
unidades[2] = unidades[0] + 5;    // Expresión
// Contenido final: {11, 25, 16}

    Asignar unidades[1] = 25 no inserta una posición nueva: cambia el contenido de una posición existente.

    2.2. Validar el índice¶

    Un índice es válido si cumple indice >= 0 && indice < array.length. Un acceso fuera de ese rango provoca ArrayIndexOutOfBoundsException durante la ejecución.

    Fichero: ActualizarPosicion.java

    import java.util.Scanner;

public class ActualizarPosicion {
    public static void main(String[] args) {
        Scanner teclado = new Scanner(System.in);
        int[] unidades = {10, 20, 30, 40};

        System.out.print("Posición que quieres modificar (0 a 3): ");
        int posicion = teclado.nextInt();

        if (posicion >= 0 && posicion < unidades.length) {
            System.out.print("Nuevo valor: ");
            unidades[posicion] = teclado.nextInt();
            System.out.println("Valor guardado: " + unidades[posicion]);
        } else {
            System.out.println("Posición no válida.");
        }
        teclado.close();
    }
}

    El programa presupone entradas enteras. La validación del formato de entrada se estudiará con el tratamiento de excepciones.

    3. Recorrido de arrays¶

    3.1. Recorrido con for¶

    Utilizamos el índice cuando necesitamos conocer posiciones o modificar elementos.

    int[] cantidades = {4, 7, 2};

for (int i = 0; i < cantidades.length; i++) {
    System.out.println("Posición " + i + ": " + cantidades[i]);
}

    Salida:

    Posición 0: 4
Posición 1: 7
Posición 2: 2

    La condición es i < cantidades.length, nunca i <= cantidades.length.

    3.2. Recorrido inverso¶

    int[] cantidades = {4, 7, 2};

for (int i = cantidades.length - 1; i >= 0; i--) {
    System.out.print(cantidades[i] + " ");
}
// Salida: 2 7 4
// El array sigue conteniendo {4, 7, 2}.

    Mostrar en orden inverso no modifica el orden del array.

    3.3. Recorrido con while¶

    int[] cantidades = {4, 7, 2};
int i = 0;
while (i < cantidades.length) {
    System.out.println(cantidades[i]);
    i++;
}

    for y while pueden recorrer un array vacío sin entrar en el cuerpo. Un do...while ejecuta el cuerpo al menos una vez: requiere comprobar antes que hay elementos si se accede a una posición.

    3.4. Recorrido con for-each¶

    int[] cantidades = {4, 7, 2};
for (int cantidad : cantidades) {
    System.out.println(cantidad);
}

    En cada iteración, cantidad recibe el valor del siguiente elemento. Este recorrido resulta cómodo para consultar datos, pero no proporciona el índice.

    La variable del recorrido no es la posición del array

    Con tipos primitivos, asignar otro valor a la variable del for-each no modifica el elemento original.

    int[] cantidades = {4, 7, 2};
for (int cantidad : cantidades) {
    cantidad = cantidad * 2;
}
// El contenido sigue siendo {4, 7, 2}.

for (int i = 0; i < cantidades.length; i++) {
    cantidades[i] *= 2;
}
// Ahora contiene {8, 14, 4}.

    En arrays de objetos, la variable recibe una copia de la referencia: permite modificar un objeto mutable, pero reasignar esa variable tampoco sustituye la referencia guardada en el array.

    3.5. Cargar valores por teclado¶

    Scanner teclado = new Scanner(System.in);
int[] cantidades = new int[4];

for (int i = 0; i < cantidades.length; i++) {
    System.out.print("Valor de la posición " + i + ": ");
    cantidades[i] = teclado.nextInt();
}
// Requiere import java.util.Scanner;
// Cerrar teclado al terminar de utilizar la entrada en el programa.

    4. Operaciones mediante métodos¶

    Java pasa por valor todos los argumentos. Cuando se pasa un array, se copia su referencia: el método puede acceder al mismo objeto y modificar sus elementos.

    public static void duplicar(int[] datos) {
    for (int i = 0; i < datos.length; i++) {
        datos[i] *= 2;
    }
}

    Uso dentro de main:

    int[] numeros = {2, 5, 8};
duplicar(numeros);
// numeros contiene {4, 10, 16}.

    Si un método crea otro array y reasigna solo su parámetro, la variable del llamador no cambia. Para utilizar el array nuevo, debe devolverlo y el llamador debe recoger el resultado.

    public static int[] crearCopia(int[] origen) {
    int[] copia = new int[origen.length];
    for (int i = 0; i < origen.length; i++) {
        copia[i] = origen[i];
    }
    return copia;
}

    int[] original = {2, 5, 8};
int[] copia = crearCopia(original);
copia[0] = 99;
// original: {2, 5, 8}; copia: {99, 5, 8}.

    En cambio, int[] copia = original; asignaría la misma referencia; no copiaría los elementos. En arrays de objetos, copiar elementos copia sus referencias, no los objetos a los que apuntan.

    5. Inserción de un elemento¶

    5.1. Crear un array con una posición más¶

    Para insertar en la posición posicion:

    1. Crear un array con longitud original.length + 1.
    2. Copiar los elementos anteriores a la posición.
    3. Guardar el nuevo valor.
    4. Copiar los elementos restantes desplazados una posición a la derecha.

    Se permite insertar desde 0 hasta original.length, incluido este último valor para añadir al final.

    /**
 * Devuelve un array nuevo con un valor insertado.
 * @param original array de origen no nulo
 * @param posicion índice de inserción, entre 0 y original.length
 * @param valor valor que se añadirá
 * @return array nuevo con una posición adicional
 * @throws IllegalArgumentException si la posición no es válida
 */
public static int[] insertar(int[] original, int posicion, int valor) {
    if (posicion < 0 || posicion > original.length) {
        throw new IllegalArgumentException("Posición de inserción no válida");
    }
    int[] resultado = new int[original.length + 1];
    for (int i = 0; i < posicion; i++) {
        resultado[i] = original[i];
    }
    resultado[posicion] = valor;
    for (int i = posicion; i < original.length; i++) {
        resultado[i + 1] = original[i];
    }
    return resultado;
}

    int[] numeros = {10, 20, 30};
numeros = insertar(numeros, 1, 15);
// Resultado: {10, 15, 20, 30}
    Paso Contenido del array nuevo
    Crear [0, 0, 0, 0]
    Copiar anteriores [10, 0, 0, 0]
    Insertar valor [10, 15, 0, 0]
    Copiar posteriores [10, 15, 20, 30]

    La instrucción throw interrumpe el método y comunica un argumento incorrecto; no es necesario capturar la excepción para utilizar estos métodos con posiciones válidas.

    5.2. Capacidad física y número de elementos utilizados¶

    También podemos reservar más posiciones de las necesarias y mantener un contador:

    int[] datos = new int[5]; // Capacidad: 5
int utilizados = 0;

if (utilizados < datos.length) {
    datos[utilizados] = 10;
    utilizados++;
}
if (utilizados < datos.length) {
    datos[utilizados] = 20;
    utilizados++;
}
// Capacidad física: 5; elementos utilizados: 2.

    En este modelo, se procesan las posiciones de 0 a utilizados - 1. El valor cero no indica por sí mismo que una posición esté libre: puede ser un dato válido.

    6. Borrado de elementos¶

    6.1. Borrado lógico¶

    Asignar 0, null u otro marcador no elimina una posición. El tamaño permanece igual y el programa debe definir cómo interpretar el marcador.

    int[] codigos = {15, 28, 36};
codigos[1] = 0;
// Contenido: {15, 0, 36}; longitud: 3.

    Si cero es un dato válido, no sirve como marcador inequívoco. Puede utilizarse un contador de elementos ocupados o un array adicional de indicadores, según el diseño.

    6.2. Eliminar por índice creando otro array¶

    /**
 * Devuelve un array nuevo sin el elemento de la posición indicada.
 * @param original array de origen no nulo
 * @param posicion índice que se eliminará
 * @return array nuevo con una posición menos
 * @throws IllegalArgumentException si el índice está fuera del array
 */
public static int[] eliminarPorIndice(int[] original, int posicion) {
    if (posicion < 0 || posicion >= original.length) {
        throw new IllegalArgumentException("Posición de borrado no válida");
    }
    int[] resultado = new int[original.length - 1];
    for (int i = 0; i < posicion; i++) {
        resultado[i] = original[i];
    }
    for (int i = posicion + 1; i < original.length; i++) {
        resultado[i - 1] = original[i];
    }
    return resultado;
}

    int[] numeros = {10, 20, 30, 40};
numeros = eliminarPorIndice(numeros, 1);
// Resultado: {10, 30, 40}; longitud: 3.

    El método sirve para eliminar el primer elemento, el último o uno intermedio. Si el original tiene un solo elemento, devuelve un array vacío.

    6.3. Alternativa con System.arraycopy¶

    System.arraycopy copia un bloque de elementos. Sus argumentos son: origen, posición inicial de origen, destino, posición inicial de destino y cantidad de elementos.

    public static String[] eliminarTextoPorIndice(String[] original, int posicion) {
    if (posicion < 0 || posicion >= original.length) {
        throw new IllegalArgumentException("Posición no válida");
    }
    String[] resultado = new String[original.length - 1];
    System.arraycopy(original, 0, resultado, 0, posicion);
    System.arraycopy(original, posicion + 1, resultado, posicion,
            original.length - posicion - 1);
    return resultado;
}

    String[] letras = {"A", "C", "B", "C", "D"};
letras = eliminarTextoPorIndice(letras, 1);
// Resultado: {"A", "B", "C", "D"}.

    La cantidad que se copia puede ser cero. El ejemplo incluye validación del índice antes de calcular los bloques.

    6.4. Eliminar por valor con streams: ampliación¶

    int[] datos = {2, 5, 2, 8};
int[] sinDos = java.util.Arrays.stream(datos)
        .filter(numero -> numero != 2)
        .toArray();
// Resultado: {5, 8}.
// datos sigue conteniendo {2, 5, 2, 8}.

    Este ejemplo devuelve otro array y elimina todas las apariciones del valor. No elimina únicamente la primera ni busca una posición. Los streams son una ampliación: primero conviene comprender los recorridos y las copias manuales.

    7. Ordenación manual¶

    Ordenar consiste en reorganizar los valores según un criterio. Los métodos siguientes modifican el array recibido, sin crear una copia.

    7.1. Burbuja¶

    Compara elementos contiguos y los intercambia cuando están desordenados. En cada pasada queda colocado el mayor valor de la zona pendiente.

    public static void ordenarBurbuja(int[] datos) {
    for (int pasada = 0; pasada < datos.length - 1; pasada++) {
        boolean cambio = false;
        for (int i = 0; i < datos.length - 1 - pasada; i++) {
            if (datos[i] > datos[i + 1]) {
                int auxiliar = datos[i];
                datos[i] = datos[i + 1];
                datos[i + 1] = auxiliar;
                cambio = true;
            }
        }
        if (!cambio) {
            break;
        }
    }
}

    Para {5, 2, 4, 1}:

    Momento Contenido
    Inicial [5, 2, 4, 1]
    Primera pasada [2, 4, 1, 5]
    Segunda pasada [2, 1, 4, 5]
    Tercera pasada [1, 2, 4, 5]

    7.2. Inserción directa¶

    Mantiene ordenada la parte izquierda. Guarda el valor actual, desplaza los anteriores que sean mayores y coloca el valor en el hueco resultante.

    public static void ordenarInsercion(int[] datos) {
    for (int i = 1; i < datos.length; i++) {
        int actual = datos[i];
        int j = i - 1;
        while (j >= 0 && datos[j] > actual) {
            datos[j + 1] = datos[j];
            j--;
        }
        datos[j + 1] = actual;
    }
}

    Para {5, 2, 4, 1}:

    Valor colocado Contenido después de colocarlo
    2 [2, 5, 4, 1]
    4 [2, 4, 5, 1]
    1 [1, 2, 4, 5]

    En la condición del while, se comprueba primero j >= 0. El operador && evita evaluar datos[j] cuando j ya es negativo.

    7.3. Selección¶

    Busca el menor elemento de la zona pendiente y lo intercambia con el primero de esa zona.

    public static void ordenarSeleccion(int[] datos) {
    for (int i = 0; i < datos.length - 1; i++) {
        int posicionMinimo = i;
        for (int j = i + 1; j < datos.length; j++) {
            if (datos[j] < datos[posicionMinimo]) {
                posicionMinimo = j;
            }
        }
        if (posicionMinimo != i) {
            int auxiliar = datos[i];
            datos[i] = datos[posicionMinimo];
            datos[posicionMinimo] = auxiliar;
        }
    }
}
    Algoritmo Idea Tiempo en el peor caso
    Burbuja Intercambiar vecinos O(n²)
    Inserción directa Insertar cada valor en la parte izquierda ordenada O(n²)
    Selección Seleccionar el mínimo restante O(n²)

    O(n²) significa que el trabajo puede crecer aproximadamente con el cuadrado del número de elementos. Burbuja con detección de cambios e inserción directa realizan O(n) trabajo si el array ya está ordenado. Selección mantiene O(n²) comparaciones. Los tres ejemplos utilizan O(1) memoria auxiliar y admiten arrays vacíos.

    7.4. Orden descendente¶

    En burbuja, cambiar datos[i] > datos[i + 1] por datos[i] < datos[i + 1] coloca los mayores primero. En inserción, se cambia datos[j] > actual por datos[j] < actual; en selección, se busca el máximo.

    8. Búsqueda¶

    8.1. Búsqueda secuencial¶

    Examina los elementos hasta encontrar el valor. No necesita que el array esté ordenado.

    public static int buscarSecuencial(int[] datos, int buscado) {
    for (int i = 0; i < datos.length; i++) {
        if (datos[i] == buscado) {
            return i;
        }
    }
    return -1;
}

    int[] datos = {8, 3, 6, 3};
System.out.println(buscarSecuencial(datos, 3)); // 1: primera aparición
System.out.println(buscarSecuencial(datos, 9)); // -1: no encontrado

    En el peor caso examina todos los elementos: O(n).

    8.2. Búsqueda binaria¶

    Requiere el array ordenado de menor a mayor. Compara con el elemento central y descarta la mitad donde no puede estar el valor.

    public static int buscarBinaria(int[] datos, int buscado) {
    int izquierda = 0;
    int derecha = datos.length - 1;
    while (izquierda <= derecha) {
        int centro = izquierda + (derecha - izquierda) / 2;
        if (datos[centro] == buscado) {
            return centro;
        }
        if (datos[centro] < buscado) {
            izquierda = centro + 1;
        } else {
            derecha = centro - 1;
        }
    }
    return -1;
}

    Para buscar 30 en {10, 20, 30, 40, 50} se consulta directamente el índice central 2 y se encuentra el valor.

    Para buscar 40, primero se consulta 30, después la mitad derecha y se encuentra 40 en la posición 3.

    El tiempo de búsqueda es O(log n), pero ordenar antes tiene un coste adicional. No suele compensar ordenar solo para realizar una búsqueda aislada. Si hay duplicados, esta versión no garantiza devolver la primera aparición.

    La posición corresponde al array actual

    Ordenar cambia las posiciones. El índice obtenido tras ordenar puede ser distinto del que tenía el dato originalmente.

    9. Herramientas de java.util.Arrays¶

    import java.util.Arrays;

    9.1. Mostrar contenido¶

    int[] datos = {7, 2, 9};
System.out.println(Arrays.toString(datos)); // [7, 2, 9]

    System.out.println(datos) no muestra los elementos con ese formato.

    9.2. Ordenar¶

    int[] datos = {7, 2, 9};
Arrays.sort(datos);
System.out.println(Arrays.toString(datos)); // [2, 7, 9]

    sort modifica el array y no devuelve otro. Dispone de versiones para tipos numéricos, char y objetos compatibles con el criterio de ordenación; no dispone de una versión para boolean[].

    En String, el orden natural distingue mayúsculas, minúsculas y acentos; no equivale necesariamente al orden alfabético de un idioma.

    String[] nombres = {"juan", "ana", "pedro"};
Arrays.sort(nombres);
// {"ana", "juan", "pedro"}

    Para ordenar un int[] en sentido descendente podemos ordenar ascendentemente e invertir después las posiciones mediante intercambios. Collections.reverseOrder() no se aplica directamente a int[]: los comparadores de Arrays.sort se utilizan con arrays de objetos, como Integer[].

    9.3. Buscar con binarySearch¶

    int[] datos = {10, 20, 30, 40};
System.out.println(Arrays.binarySearch(datos, 30)); // 2
System.out.println(Arrays.binarySearch(datos, 25)); // -3

    El array debe estar previamente ordenado. Si no encuentra el valor, devuelve -(puntoDeInsercion) - 1, no necesariamente -1. Para comprobar si lo encuentra, se utiliza resultado >= 0. Para 25, el punto de inserción es 2 y el resultado es -3.

    9.4. Rellenar: corrección de la firma¶

    int[] datos = new int[5];
Arrays.fill(datos, 7);
// [7, 7, 7, 7, 7]

Arrays.fill(datos, 1, 4, 9);
// [7, 9, 9, 9, 7]

    La firma por intervalo es Arrays.fill(array, desde, hasta, valor). Se incluye desde y se excluye hasta: [desde, hasta). No debe escribirse el valor antes de los índices.

    9.5. Copiar y extraer un intervalo¶

    int[] origen = {7, 5, 3, 1};
int[] corta = Arrays.copyOf(origen, 2);  // [7, 5]
int[] larga = Arrays.copyOf(origen, 6);  // [7, 5, 3, 1, 0, 0]
int[] tramo = Arrays.copyOfRange(origen, 1, 3); // [5, 3]

    Estas operaciones crean otro array. En copyOfRange, el límite final queda excluido. Al ampliar mediante copyOf, las posiciones nuevas reciben el valor predeterminado del tipo.

    9.6. Comparar contenido¶

    int[] primero = {1, 2, 3};
int[] segundo = {1, 2, 3};
int[] tercero = {3, 2, 1};

System.out.println(primero == segundo); // false: referencias distintas
System.out.println(Arrays.equals(primero, segundo)); // true
System.out.println(Arrays.equals(primero, tercero)); // false

    Arrays.equals compara longitud y elementos en el mismo orden. El nombre correcto es Arrays.equals, no Array.equals.

    10. Programa completo: insertar, buscar y borrar¶

    Este programa muestra las operaciones manualmente, sin utilizar Arrays. Guárdalo como DemoOperaciones.java.

    public class DemoOperaciones {
    public static void main(String[] args) {
        int[] datos = {10, 20, 30};
        mostrar(datos);
        datos = insertar(datos, 1, 15);
        mostrar(datos);
        System.out.println("Posición de 20: " + buscar(datos, 20));
        datos = eliminar(datos, 2);
        mostrar(datos);
    }

    public static void mostrar(int[] datos) {
        System.out.print("[");
        for (int i = 0; i < datos.length; i++) {
            if (i > 0) {
                System.out.print(", ");
            }
            System.out.print(datos[i]);
        }
        System.out.println("]");
    }

    public static int buscar(int[] datos, int valor) {
        for (int i = 0; i < datos.length; i++) {
            if (datos[i] == valor) {
                return i;
            }
        }
        return -1;
    }

    public static int[] insertar(int[] datos, int posicion, int valor) {
        if (posicion < 0 || posicion > datos.length) {
            throw new IllegalArgumentException("Posición no válida");
        }
        int[] nuevo = new int[datos.length + 1];
        for (int i = 0; i < posicion; i++) {
            nuevo[i] = datos[i];
        }
        nuevo[posicion] = valor;
        for (int i = posicion; i < datos.length; i++) {
            nuevo[i + 1] = datos[i];
        }
        return nuevo;
    }

    public static int[] eliminar(int[] datos, int posicion) {
        if (posicion < 0 || posicion >= datos.length) {
            throw new IllegalArgumentException("Posición no válida");
        }
        int[] nuevo = new int[datos.length - 1];
        for (int i = 0; i < posicion; i++) {
            nuevo[i] = datos[i];
        }
        for (int i = posicion + 1; i < datos.length; i++) {
            nuevo[i - 1] = datos[i];
        }
        return nuevo;
    }
}
